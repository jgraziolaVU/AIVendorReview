## Requested Documentation

Please provide the most recent versions of the following:

### Required
- [ ] **SOC 2 Type II Report** (or SOC 3 if Type II is under NDA — we can execute an NDA)
- [ ] **Information Security Policy** (or Security Overview / Trust Center documentation)
- [ ] **Data Processing Agreement (DPA)** or **Business Associate Agreement (BAA)** if applicable

### Strongly Preferred
- [ ] **Penetration Test Summary** — most recent external pen test (date, scope, findings summary)
- [ ] **SIG (Standardized Information Gathering) Questionnaire** or equivalent vendor security questionnaire
- [ ] **Subprocessor List** — third-party vendors with access to data processed on our behalf
- [ ] **Incident Response / Breach Notification Policy** — including notification timeline

### If Applicable
- [ ] **FedRAMP Authorization Letter** (if your product is FedRAMP authorized)
- [ ] **ISO 27001 Certificate** (if applicable)
- [ ] **HIPAA / FERPA Compliance Documentation** (if our data includes PHI or student records)
- [ ] **Data Residency Documentation** — where is data stored and processed?
